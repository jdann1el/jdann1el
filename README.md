## hey, I'm john

Advertising and design student in Barcelona.

I'm interested in what happens when AI agents make design work. Right now most of it looks like a template with a stock photo. I'm writing skills that give agents better judgment on concept, type and hierarchy, and testing them blind against the same agent without the skill.

Outside of that I build small automations for studio work, read a lot about agents that use computers, and paper-trade with an agent to see how far it gets.

## Building

### [cropmark](https://github.com/jdann1el/cropmark) &nbsp;<img src="https://img.shields.io/github/v/release/jdann1el/cropmark?style=flat&color=f4dc3c&label=" alt="latest release" /> <img src="https://img.shields.io/github/stars/jdann1el/cropmark?style=flat&color=24292f" alt="stars" />

An open Agent Skill that makes Claude Code, Codex, Cursor and 70+ agents design YouTube thumbnails, posts and carousels at portfolio level. 18 style cards, two render engines, QA you can run. In a blind test it beat the same agent without the skill in 9 of 12 briefs.

```bash
npx skills add jdann1el/cropmark
```
