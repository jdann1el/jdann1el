## hey, I'm john

I study advertising and design in Barcelona, and I spend the rest of my time on the place where design meets AI agents.

Most AI-made graphics look like templates with a stock photo. I'm working on that gap: giving agents real design judgment (concept, type, hierarchy, a single focal point) and then testing it blind against the agent without it. I also build automations for studio work: research, outreach and content pipelines that run on agents instead of on me.

- 🔨 **Now:** shipping [cropmark](https://github.com/jdann1el/cropmark) and testing it in Claude Code, Codex and Hermes
- 🧠 **Exploring:** agents that use computers, AI-assisted development, autonomous paper trading
- 🎨 **Background:** advertising, editorial and social design
- 💬 **Talk to me about:** agent skills, design systems for AI output, automation

## Building

### [cropmark](https://github.com/jdann1el/cropmark) &nbsp;<img src="https://img.shields.io/github/v/release/jdann1el/cropmark?style=flat&color=f4dc3c&label=" alt="latest release" /> <img src="https://img.shields.io/github/stars/jdann1el/cropmark?style=flat&color=24292f" alt="stars" />

An open Agent Skill that makes Claude Code, Codex, Cursor and 70+ agents design YouTube thumbnails, posts and carousels at portfolio level. 18 style cards, two render engines, QA you can run. In a blind test it beat the same agent without the skill in 9 of 12 briefs.

```bash
npx skills add jdann1el/cropmark
```
